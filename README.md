# AI Job Application Agent

An AI-powered job application assistant built using n8n and Google Gemini.

## Features

- Generates personalized cover letters
- Creates professional application emails
- Calculates candidate-job match scores
- Identifies missing skills
- Generates interview preparation questions

## Workflow

User Input:
- Job Role
- Company Name

AI Output:
- Cover Letter
- Application Email
- Match Score
- Missing Skills Analysis
- Interview Questions

## Tech Stack

- n8n
- Google Gemini
- Prompt Engineering
- Workflow Automation
- API Integration

## Project Goal

To automate the job application preparation process using Large Language Models (LLMs) and workflow automation.
